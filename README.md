# tamash-selenium (placeholder)

**`tamash-selenium` is a Java / Maven package, not a Python one.**

This PyPI name is a placeholder, published by the maintainers of `tamash-selenium` so the name
can't be squatted. There is no Python distribution and none is planned — the self-healing engine
for Selenium is a Java library.

| | |
|---|---|
| **Maven Central** | `com.vibetestq.qtpsudhakar:tamash-selenium` |
| **Docs** | <https://qtpsudhakarproducts.github.io/tamash-selenium/> |
| **Source** | <https://github.com/qtpsudhakarproducts/tamash-selenium> |

Installing this package and importing it raises `ImportError` with a pointer to the real artifact.

### Looking for Python self-healing?

`tamash-selenium`'s sibling project **[`tamash-playwright`](https://pypi.org/project/tamash-playwright/)**
brings the same runtime self-healing to Playwright, and *is* available for Python (pytest /
pytest-bdd). See <https://qtpsudhakarproducts.github.io/tamash-playwright-support/>.
